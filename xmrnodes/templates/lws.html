About Light-Wallets

Monero wallets require complex scanning and decryption against every transaction on the blockchain to determine if funds were sent to that wallet. This means that every time you go to spend your Monero you must wait for your device to get synced up which can take a long time.

This process can be offloaded to a remote server without giving up the "spend" keys of the wallet. The LWS (Light Wallet Server) API provides a standard mechanism for splitting the "scanning" process from the "spend" process, giving light wallets an instant sync instead of polling the entire chain.

The only downside of this is privacy - the LWS server knows all incoming funds. Make sure this trade-off fits your threat model before registering. If you need full privacy, run your own node and your own LWS instance instead.

The list below contains community run, open-source LWS instances for you to use.

Helpful links:

  • Skylight Wallet - open-source light-wallet (iOS, Android, Linux, Windows)
  • monero-lws - open-source LWS instance, community standard project
  • lwsadmin - pre-built LWS with hosting panel for personal use
